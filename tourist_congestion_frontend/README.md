# 여유로 Flutter 프런트엔드

실시간 혼잡도 기반 장소 추천 앱의 프런트엔드 기본 틀입니다.
서버, 데이터베이스, 로그인, 지도 SDK, 관광공사 API 연결은 포함하지 않았으며 화면에는 임시 데이터가 표시됩니다.

## 포함 화면

- 홈: 현재 위치, 검색, 3:4 지도 자리, 혼잡도 핀, 장소 카드
- 추천: 카테고리 필터와 맞춤 장소 목록
- 저장: 저장한 장소 목록
- 마이페이지: 프로필 및 설정 메뉴
- 하단 탭 화면 이동

## 실행 방법

Flutter가 설치된 폴더에서 아래 명령을 실행합니다.

압축을 푼 폴더에서 플랫폼 파일을 만든 뒤 실행합니다.

```bash
flutter create --platforms=android,ios,web .
flutter pub get
flutter run
```
