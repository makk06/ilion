# 🔴 쓰기 전에 읽을 것

## 처리방침은 실제 처리와 일치해야 합니다

**§30은 수립·공개 의무이며, 템플릿을 그대로 붙여넣고 실제와 다르면 그 자체가 위반입니다.**

## 순서를 바꿀 수 없는 의존 관계

**회원 탈퇴 기능과 항목별 보유기간·파기 정책이 정해지기 전에는 이 문서를 쓸 수조차 없습니다.**

§15②3(보유·이용 기간 고지)과 §30(처리방침 기재사항)은 둘 다 "얼마나 보관하고 언제 어떻게 파기하는가"를 요구합니다. 이것이 정해지지 않은 상태에서 처리방침을 작성하면 **그 문서 자체가 §30 위반물**이 됩니다.

```
① 보유기간 확정 + 탈퇴 시 항목별 처리(삭제/익명화/보존) 결정
         ↓
② 파기 로직 구현
         ↓
③ 처리방침 작성
         ↓
④ 공개
```

> **`PD-B-023`(포인트 원장)이 병목입니다.** `PointEntry.place`가 `PROTECT`라 **보존/파기 결정 없이는 탈퇴 로직 자체를 짤 수 없습니다.** 전자상거래법 보존 의무 해당 여부를 먼저 확인하십시오. **[검증 필요]**

## 🔴 §9 "안전성 확보 조치" 절의 전제

[보안 결함 6건](security-findings.md)이 미해소인 상태에서 §9 절을 작성하면 **그 절 자체가 허위 기재가 됩니다.**

## 1. 절 구성과 각 절에 들어갈 내용

법정 기재사항 14개 절입니다.

### §1 개인정보의 처리 목적

계정 생성·로그인, 서비스 내 이용자 표시, 게시물 제공, 여행 일정 관리, 문의 응대, 포인트 서비스, (동의 시) 개인화·추천 개선, (동의 시) 현재 위치 기반 주변 안내.

**선행 조건**: 없음

### §2 처리하는 개인정보의 항목 — **필수/선택 구분 표기**

| 구분 | 항목 |
|------|------|
| **[동의 불요 · 계약 이행]** | 이메일, 비밀번호, 닉네임, 가입 경로, 인증 토큰, 찜, 후기, 동행글, 여행 일정, 문의, 포인트 이력 |
| **[선택 동의]** | 최근 본 장소, 선호 카테고리, 피드백 |
| **[별도 동의]** | 현재 위치(위도·경도) |

**선행 조건**: `PD-B-011`(`last_login`) 처리 여부 결정 · `STOP-COLLECT` 14건 실제 제거

> **주의**: 여기에 적은 항목 목록이 **실제 수집 항목과 일치해야 합니다.** `STOP-COLLECT` 14건을 제거하지 않은 채 목록에서 빼면 불일치가 됩니다.

### §3 개인정보의 처리 및 보유 기간

아래 [2. 보유기간 초안](#2-보유기간-초안-1523-고지용)을 확정한 뒤 옮기십시오. **법정 보존 항목이 있으면 예외로 함께 기재**해야 합니다.

**선행 조건**: 🔴 **보유기간 확정**

### §4 개인정보의 제3자 제공

**현재 "없음"입니다.**

동행글·후기의 비로그인 공개는 제3자 제공(§17)이 아니라 **서비스 구조상 공개**이므로, §2·§5가 아니라 **공개 범위 설명**으로 다룹니다.

**선행 조건**: 없음

### §5 개인정보 처리의 위탁

현재 코드상 식별된 수탁자가 **없습니다** (클라우드·분석 SDK·푸시 서비스 없음).

> **[검증 필요]** 실제 배포 환경의 **호스팅·미디어 서빙 주체**는 저장소 밖이므로 확인 후 기재하십시오.
> 향후 푸시(`PD-B-060`)·리워드 발급(`PD-B-061`) 도입 시 **위탁/제공 구분을 먼저 판정**하십시오.
> 위탁은 동의 대상이 아니라 **처리방침 공개 대상**입니다(§26).

**선행 조건**: 인프라 확인

### §6 개인정보의 국외 이전

구글 로그인 이용 시 Google LLC로 인증 토큰 전송.

> **[검증 필요]** §28의8 각 호 확인 결과에 따라 **"동의" 또는 "고지"로 기재 방식이 달라집니다.**
> OpenFreeMap 벡터 타일(`PD-F-047`)을 활성화하면 이 절이 확대됩니다.

**선행 조건**: §28의8 원문 확인

| 경로 | 판정 |
|------|------|
| 구글 ID Token 검증 | **현재 발생 중** — 이 절에 기재 필요 |
| 브이월드 지도 타일 | **국내.** 서버 프록시라 이용자 IP 미전달 → 국외 이전 아님 |
| 카카오맵 길찾기 | **국내** → 국외 이전 아님 |
| OpenFreeMap 벡터 타일 | 현재 런타임 경로 없음. **활성화 시 발생** |

### §7 개인정보의 파기 절차 및 방법

보유기간 경과·목적 달성 시 지체 없이 파기. 전자적 파일은 복구 불가능한 방법으로 삭제하며, **업로드 사진 파일은 게시물 삭제 시 동시 삭제**합니다.

**선행 조건**: 🔴 **파기 로직 구현.** 현재 `Review.delete()`가 `photo` 파일을 남깁니다

### §8 정보주체와 법정대리인의 권리·의무 및 행사 방법

열람·정정·삭제·처리정지 요구 방법, **회원 탈퇴 방법**, 접수 창구.

> 문의·피드백·포인트 원장은 현재 **개별 삭제 수단이 없으므로**, 최소한 **삭제 요구 접수 창구**를 명시하고 운영 절차를 정해야 합니다. §36은 보유기간과 무관하게 삭제 요구권을 규정합니다.

**선행 조건**: 🔴 **탈퇴 API 구현**

### §9 개인정보의 안전성 확보 조치

비밀번호 일방향 암호화, 전송 구간 암호화, 접근 권한 최소화, **접속기록 보관·점검**, 토큰 보안 저장.

> ### 🔴 이 절은 마지막에 쓰십시오
> [보안 결함 6건](security-findings.md)과 접속기록 도입(`PD-B-054`)이 미해소 상태에서 이 절을 쓰면 **허위 기재**가 됩니다.
> 특히 "접속기록을 보관·점검합니다"는 현재 **`logging` 사용처가 0건**이므로 명백히 거짓입니다.

**선행 조건**: 🔴 `PD-R-001` · `PD-R-003` · 접속기록 · `PD-B-043` · `PD-B-031`/`063` 해소

### §10 개인정보 자동 수집 장치의 설치·운영 및 거부

앱이므로 쿠키는 해당하지 않습니다. 대신 **최근 본 장소 자동 기록과 그 거부 방법(설정 토글)**을 기재합니다.

**선행 조건**: 토글 구현

### §11 자동화된 결정에 관한 사항

추천 알고리즘.

> **[검증 필요]** §37의2 "권리·의무에 중대한 영향"에 해당하는지는 다툼 여지가 있습니다. 단순 콘텐츠 추천이 여기에 해당하는지 확정되지 않았습니다.
> **기준·절차를 공개하는 것이 안전한 대응**입니다.

**선행 조건**: 없음 (보수적으로 기재 권고)

### §12 개인정보 보호책임자 및 담당 부서

이름·직책·연락처.

**선행 조건**: 🔴 **CPO 지정 (§31)**

### §13 권익침해 구제 방법

개인정보분쟁조정위원회, 개인정보침해신고센터, 대검찰청, 경찰청 연락처.

**선행 조건**: 없음

### §14 처리방침의 변경에 관한 사항

시행일자, 이전 버전 열람 경로.

**선행 조건**: 없음

## 3. 보유기간 초안 (§15②3 고지용)

> ## ⚠ 이것은 권고 초안입니다 — 확정 전입니다
> **제품·법무 확정 전까지 처리방침에 그대로 옮겨 적지 마십시오.**
> 다만 `명시 없음` 상태로 두면 §15②3 고지가 불가능하므로, **확정 전이라도 이 초안을 기준으로 파기 배치를 설계**하십시오.

| 구분 | 권고 보유기간 |
|------|-------------|
| 계정 정보 (이메일·비밀번호·닉네임·가입 경로·구글 식별자·상태·일시) | 탈퇴 시 지체 없이 파기 (재가입 악용 방지 해시는 최대 30일, 별도 고지) |
| 인증 토큰 (RefreshToken) | `expires_at` 경과 즉시 삭제 — 일 1회 배치, 최장 15일 |
| 게시물 (후기·사진·평점) | 삭제 시 즉시 (**파일 포함**) / 탈퇴 시 삭제 또는 익명화 **(정책 결정 필요)** |
| 동행 모집 | 모집 날짜 경과 후 30일 |
| 즐겨찾기·취향·관심 지역·알림 설정 | 탈퇴 시 파기 |
| 최근 본 장소 | 최종 조회일로부터 6개월 + 50건 롤링 |
| 여행 일정 | 일정 날짜 경과 후 1년 |
| 1:1 문의 | 처리 완료 후 1년 **[검증 필요]** 전자상거래법 3년 적용 여부 |
| 포인트 원장 | 탈퇴 시 파기 **[검증 필요]** 전자상거래법 보존 의무 (부정 적립 검증 목적 보관 시 최대 1년) |
| 피드백 | 익명 저장 시 제한 없음 / 식별자 연결 시 1년 |
| 위치 좌표 | **저장하지 않음.** 웹서버 로그의 좌표는 3개월 이내 삭제·마스킹. 이용·제공 사실 확인자료는 법정 기간 **[검증 필요]** |
| 검색어·필터 | 저장하지 않음. 로그 3개월 |
| 접속기록·관리자 작업 로그 | 1년 이상 **[검증 필요]** 「개인정보의 안전성 확보조치 기준」 고시 |
| 관리자 세션 | `SESSION_COOKIE_AGE` 1일 + 만료 세션 정리 배치 |

### 확정이 필요한 결정 3건

| # | 결정 사항 | 왜 막혀 있는가 |
|---|----------|--------------|
| 1 | **탈퇴 시 후기·동행글을 삭제할 것인가, 익명화할 것인가** | 다른 이용자가 참조 중인 콘텐츠라 단순 삭제가 답이 아닐 수 있습니다 |
| 2 | **포인트 원장을 탈퇴 후에도 보존할 것인가** | 전자상거래법 보존 의무 확인이 선행. **`PointEntry.place`가 `PROTECT`라 탈퇴 로직의 병목** |
| 3 | **1:1 문의의 보유기간** | 전자상거래법 3년 적용 여부 확인 필요 |

## 4. 현재 쓸 수 없는 문장들

처리방침 템플릿에 흔히 들어가지만, **ILION의 현재 상태에서는 거짓이 되는 문장**입니다.

| 문장 | 왜 지금은 거짓인가 | 언제 쓸 수 있는가 |
|------|------------------|-----------------|
| "접속기록을 보관·점검합니다" | `logging`·`logger` 사용처 **0건** | 접속기록 도입 후 |
| "보유기간이 경과하면 지체 없이 파기합니다" | 파기 배치가 **하나도 없음** | 파기 로직 구현 후 |
| "회원 탈퇴 시 개인정보를 파기합니다" | 탈퇴 엔드포인트 자체가 **없음** | 탈퇴 API 구현 후 |
| "최종 로그인 일시를 수집합니다" | `last_login`이 **영원히 NULL** | `PD-B-011` 결정 후 |
| "민감정보를 수집하지 않습니다" | 자유서술 필드로 **유입될 수 있고 탐지 절차가 없음** | 유입 탐지·삭제 절차 수립 후 |
| "암호화 등 안전성 확보 조치를 하고 있습니다" | 서명키가 **저장소에 평문 커밋** | `PD-R-001` 해소 후 |
