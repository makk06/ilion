## 문안이 지켜야 할 규칙

### 모든 동의 블록에 4요소가 들어가야 합니다 (§15②)

1. 수집·이용 **목적**
2. 수집 **항목**
3. 보유·이용 **기간**
4. **동의 거부권**과 거부 시 **불이익**

**4번이 가장 자주 누락됩니다.** 그리고 4번을 쓸 때 **과장하지 않는 것**이 중요합니다. 선택 항목인데 "서비스 이용이 제한됩니다"라고 적으면, **그 문구 자체가 사실상의 강제로 평가될 수 있습니다.**

### 금지 패턴

| 패턴 | 왜 문제인가 |
|------|-----------|
| 「전체 동의」 하나로 필수·선택·마케팅 일괄 처리 | 구분 동의 의무 위반 소지 |
| 선택 체크박스 기본 체크 | 유효한 동의로 보기 어려움 |
| "서비스 이용을 위해 모든 항목에 동의가 필요합니다" | 선택 항목까지 강제 |
| 선택 항목에 "미동의 시 서비스 이용 불가" 표기 | 사실과 다르면 그 자체가 위반 소지 |
| 약관 동의로 개인정보 동의를 갈음 | 별도 구분 필요 |
| 보유기간을 "탈퇴 시까지"로만 적고 예외 미기재 | 법정 보존 항목이 있으면 함께 적어야 함 |
| 스크롤 없이 읽을 수 없는 긴 문단 | 실질적 고지로 보기 어려움 |

### 🔴 `[결정 필요]` — 연령 확인 블록은 아직 확정할 수 없습니다

`[필수] 만 14세 이상입니다` 같은 **자기신고형 체크박스 한 줄은 §22의2가 요구하는 "법정대리인의 동의"를 갈음하지 못합니다.**

| 안 | 내용 | 비용 |
|----|------|------|
| ① | 생년월일 입력 → 만 14세 미만 **가입 차단** | 낮음. 단순하고 일반적 |
| ② | **법정대리인 동의 절차** 구현 | 높음. 동의 확인 수단 필요 |

> **"아무것도 안 하기"는 선택지가 아닙니다.** 위치 기능을 유지하면 위치정보법 아동 특례가 추가로 걸려 **이중 의무**가 됩니다. 방식이 결정되기 전까지 이 블록은 초안 상태로 둡니다.

### 이 화면에 절대 들어가면 안 되는 것

| 넣지 말 것 | 어디로 가야 하는가 |
|-----------|------------------|
| `[필수] 개인정보 수집·이용 동의` 체크박스 | 아예 만들지 않습니다 (§15①4로 동의 불요) |
| 위치 동의 | 문안 C — 위치 기능 첫 사용 시점 |
| 국외 이전 동의 | 문안 B — 구글 버튼 탭 시점 |
| 마케팅 동의 | 문안 D — 현재는 존재하지 않아야 함 |
| "전체 동의" 하나로 묶기 | §22 구분 동의 위반 |
| `[선택]` 체크박스의 기본 선택 상태 | 유효한 동의로 보기 어려움 |

## 문안 C — 위치정보 (독립 블록)

**위치는 개인정보 동의와 화면상으로도 분리합니다.** 근거 법률이 다르고, 별도 약관·일시중지 토글·철회 경로·이용 사실 기록이 따라옵니다.

- **노출 시점**: 홈의 `내 주변 10km` 또는 지도의 `현재 위치`를 **처음 탭할 때.** 회원가입 화면이 아닙니다.

```
│  동의하지 않으셔도 서비스 이용에 아무 제한이 없습니다. │
│  동의 후에도 설정에서 언제든지 수신을 거부하실 수      │
│  있습니다.                                          │
│                                                    │
│  [ ] 이메일로 받기 (선택)                            │
│  [ ] 앱 푸시로 받기 (선택)                           │
│  [ ] 밤 9시 ~ 아침 8시에도 받기 (선택)                │
└───────────────────────────────────────────────────┘
```

### 여기에 넣으면 안 되는 것

**혼잡도 변화·동행 활동·후기 반응 알림은 광고가 아닙니다.** 이용자가 직접 설정한 서비스 알림이며, 본인 활동에 대한 응답입니다.

> **현재의 유형별 개별 토글 구조를 그대로 유지하십시오.** 마케팅과 합치면 망법 §50 위반이 됩니다.

## 문안 E — 고지 문구 7종 (동의 아님)

**체크박스형 동의가 아니라 작성·행위 시점의 고지입니다.** 별도 동의로 오분류하지 마십시오.

| 화면 / 위치 | 문구 |
|-----------|------|
| 후기 작성 화면 상단 | 작성하신 후기와 사진은 로그인하지 않은 사람에게도 공개됩니다. |
| 닉네임 입력란 아래 | 닉네임은 후기·동행 글에서 다른 이용자(로그인하지 않은 사람 포함)에게 보입니다. |
| 좋아요 버튼 근처 | 좋아요를 누르면 작성자에게 내 닉네임이 전달됩니다. |
| 동행 신청 버튼 근처 | 신청하면 모집자에게 내 닉네임이 전달됩니다. |
| 길찾기 버튼 근처 | 외부 서비스(카카오맵)로 이동합니다. |
| 자유서술 입력란 하단 (후기·동행·문의·피드백) | 건강·신념 등 민감한 개인정보는 입력하지 말아 주세요. |

### 동행 게시 직전 확인 화면

```
┌───────────────────────────────────────────────────┐
│  이 글은 로그인하지 않은 사람에게도 공개됩니다.        │
│                                                    │
│  날짜   2026-10-03                                 │
│  시각   14:00                                      │
│  장소   성산일출봉                                  │
│                                                    │
│  위 내용이 함께 공개됩니다.                          │
│                                                    │
│  [ 수정 ]              [ 이대로 게시 ]              │
└───────────────────────────────────────────────────┘
```

> **날짜·시각 '미정' 선택지를 기본값으로 노출하십시오.** 모델이 이미 `null`을 허용합니다.

### ⚠ 고지만으로는 부족합니다

**고지는 작성자에게 알릴 뿐 제3자의 수집을 전혀 막지 못합니다.** 동행 모집의 실제 위험을 줄이려면 [노출 축소 4건](security-findings.md)을 함께 처리해야 합니다.
