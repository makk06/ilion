## 작업 분담과 의존성

| 담당 | 범위 | 의존성 |
| --- | --- | --- |
| 서버 에이전트 | Django 사용자 활동 모델·API·마이그레이션·테스트 | 기존 User, Place, JWT 재사용 |
| 장소 에이전트 | 장소 모델·서비스·홈·지도·상세·주변 대안 | 기존 장소 API, 공통 HTTP·인증 |
| 활동 에이전트 | 후기·동행·프로필·일정·문의·포인트 화면 | 사용자 활동 API, 공통 HTTP·인증, Place |

같은 파일은 동시에 수정하지 않도록 소유권을 나눴으며, 에이전트 완료 이후 메인이 최종 포맷·수정·검증했습니다. 기존 작업 파일은 보존했고 원격 push/merge는 하지 않았습니다.

## 검증 증거

- Flutter 정적 분석: No issues found.
- Flutter 테스트: 24개 (공통 API, 세션 복원/로그아웃 응답 경합, 후기 생성/실패/화면 간 갱신, 동행 참여/취소, 장소 계약, 지도 선택/뒤로가기, 앱 흐름).
- Django 전체 테스트: 67개 통과. 시스템 검사 정상, 미반영 마이그레이션 없음.
- 실행 중인 실제 HTTP 서버: 검색/상세/주변 거리, CORS preflight, 회원가입, 즐겨찾기, 최근 기록, multipart 사진 후기 CRUD, 좋아요 중복 방지, 포인트, 동행 정원/참여/취소, 알림, 환경설정, 일정, 문의 검증 통과.
- 실제 브라우저: 장소 목록/혼잡도 개발샘플 표기, 로그인 후 원래 장소 복귀 및 저장, 후기 등록 후 상세 평점/다른 탭 갱신, 저장 목록, 재실행 상태 복원 확인.
- 390×844 모바일 뷰포트에서 후기 및 실제 지도 타일/마커/목록 전환 레이아웃 확인.
- 웹 release 및 Android debug APK 빌드 검증. Windows C:/D: 드라이브 차이로 발생한 Kotlin incremental cache 오류는 프로젝트 gradle.properties 설정으로 해결.

## 운영 연동과 검증 한계

- 로컬 실행 검증은 저장소의 개발 시드 10개를 DB에 적재해 수행했습니다. 실제 공공데이터 공급자의 최신 데이터 수집을 검증한 것은 아닙니다. 개발 혼잡도는 화면에 샘플로 표시합니다.
- 실제 GPS/사진 권한 흐름과 카카오맵 앱 간 이동은 실기기에서 추가 확인이 필요합니다. 브라우저 위치 권한을 임의로 승인하지 않았습니다.
- iOS 빌드/서명은 Windows 환경에서 검증하지 않았습니다.
- 제휴 리워드 실물/쿠폰 발급, 푸시 알림 전송, 사진 기반 방문 진위 판정, 자체 혼잡도 예측은 공급자·운영 정책이 없어 구현 완료로 주장하지 않습니다. 해당 기능이 완료됐다는 가짜 안내는 제거했습니다. 앱 내 활동 알림과 포인트 적립은 서버에 연결됩니다.
- 공개 배포 시 HTTPS API 주소, CORS origin, 공공데이터 갱신 작업, 미디어 호스팅을 운영 환경에 맞춰 설정해야 합니다.

## 로컬 확인

현재 검증 서버는 http://127.0.0.1:8011 이고 웹 프리뷰는 http://127.0.0.1:7357 입니다. 최종 검증 APK는 Android 에뮬레이터에서 http://10.0.2.2:8011/api 를 사용합니다. 기본 실행 방법은 프런트엔드 README와 docs/activity-api.md를 참고하세요.
