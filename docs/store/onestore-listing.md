# 원스토어 등록 자료 — 이리ON 1.0.0

작성일: 2026-09-21 · 기준 브랜치: `release/onestore-1.0.0`
규격 출처: [원스토어 개발자센터 — 판매정보](https://onestore-dev.gitbook.io/dev/docs/apps/product/android/app-info), [바이너리](https://onestore-dev.gitbook.io/dev/docs/apps/product/android/binary)

> 이 문서의 문구는 **이번 빌드에 실제로 있는 기능만** 적었다. 기능이 바뀌면 문구도 같이 고친다.
> 특히 이번 릴리스는 기기 위치 기능을 끈 상태이므로 "현재 위치", "내 주변" 같은 표현을 쓰지 않는다.

## 1. 판매정보 — 콘솔에 그대로 붙여넣기

### 상품제목 (최대 50자)

```
이리ON - 덜 붐비는 여행지 찾기
```

### 한줄설명 (최대 100자)

```
가려는 곳이 붐빌까 걱정된다면, 예상 혼잡도를 미리 보고 덜 붐비는 대안을 찾아보세요.
```

### 상품설명 (최대 1,300자)

```
사람 많은 땐, 이리ON.
가고 싶은 관광지가 얼마나 붐빌지 미리 가늠하고, 덜 붐비는 대안을 찾아보세요.

■ 전국 관광지 예상 혼잡도
전국 관광지의 예상 혼잡도를 '매우 여유'부터 '매우 혼잡'까지 한눈에 보여드려요.
근거 자료가 부족한 곳은 신뢰도가 낮다는 표시를 함께 보여드려서, 숫자만 믿고 헛걸음하지 않도록 했어요.
서울 일부 지역은 서울시가 제공하는 관측 자료도 함께 확인할 수 있어요.

■ 취향에 맞춘 장소 추천
관심 있는 분야에 맞춰 가볼 만한 장소를 추천해 드려요.
날씨 정보가 있는 곳은 날씨까지 고려해요.

■ 지도와 목록으로 둘러보기
지역을 골라 지도나 목록으로 관광지를 살펴보고,
마음에 드는 곳은 카카오맵 길찾기로 바로 이어갈 수 있어요.

■ 후기와 동행 모집
다녀온 곳의 후기를 사진과 함께 남기고,
같은 곳에 함께 갈 사람을 모집하거나 참여할 수 있어요.

■ 나만의 여행 준비
가고 싶은 곳을 저장하고 여행 일정을 만들어 두세요.
활동에 따라 포인트도 쌓여요.

[안내]
· 혼잡도는 공공데이터를 바탕으로 계산한 예상치로, 현장 상황과 다를 수 있어요.
· 이리ON은 휴대폰의 위치 정보를 사용하지 않아요. 지역은 직접 선택해 주세요.
· 정보 출처: 한국관광공사 TourAPI(관광정보), 서울특별시(혼잡도 관측), 기상청(날씨), 브이월드(지도)
```

### 검색 키워드 (1~10개)

```
여행, 관광지, 혼잡도, 국내여행, 여행지추천, 한적한곳, 나들이, 동행, 여행후기, 여행일정
```

## 2. 이미지 규격

| 항목 | 규격 | 상태 |
|---|---|---|
| 대표 아이콘 | 512×512, PNG/JPG | `docs/store/assets/icon-512.png` (원본 로고로 생성) |
| 그래픽 이미지 | 1024×578, PNG/JPG (상세화면 상단 배너) | `docs/store/assets/graphic-1024x578.png` (로고 + 문구) |
| 스크린샷 | 2~8장, 장당 1MB 이하, 가로·세로 1,300px 이하, PNG/JPG. 권장 세로 720×1280 | ✅ 4장 준비 |

스크린샷은 릴리스 APK를 에뮬레이터에 설치하고 화면을 720×1280으로 맞춰 캡처했다. 모두 운영 서버의 실제 데이터다.

| 파일 | 화면 | 크기 |
|---|---|---|
| `screenshots/01_home_list.png` | 홈 — 종로구 장소 목록과 예상 혼잡도 | 720×1280, 172KB |
| `screenshots/02_place_detail.png` | 장소 상세 — 혼잡도·추정 근거·카카오맵 길찾기 | 720×1280, 547KB |
| `screenshots/03_recommend.png` | 맞춤 장소 추천 | 720×1280, 185KB |
| `screenshots/04_map.png` | 지도 — 종로구 장소 핀 | 720×1280, 429KB |

동행·후기 탭은 운영 서버에 아직 글이 없어 빈 화면이라 제외했다. 가짜 글을 만들어 찍지 않는다.
실제 이용자 글이 쌓이면 그 화면을 추가한다.
