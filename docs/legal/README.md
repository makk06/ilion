## 이번에 바뀐 처리

- 프런트 `deviceLocationEnabled=false`. 위치 버튼 숨김, 위치 서비스 진입 차단,
  Android/iOS 위치 권한 선언 비활성화. 직접 고른 지역·관광지 기준 검색/지도는 유지.
- 탈퇴 신청 즉시 세션 종료. 기존 7일 철회 기간에는 사진 유지.
- 7일 후 `purge_withdrawn_users`가 현재 첨부 사진 파일을 먼저 삭제하고 후기의 사진 참조를 비움.
  파일 삭제 실패 시 계정 참조를 유지해 다음 실행에서 재시도. 글·평점 및 기존 활동 보존 정책은 유지.
- 사진 파일 삭제는 DB 롤백으로 되돌릴 수 없음. 취소 기한 이후에만 실행하며 부분 실패는 재시도.

## 공개 전에 필요한 결정·구현

- 운영 주체·대표자·연락처·주소·보호책임자·공고/시행일, 가입 연령 정책과 확인 방법 확정.
- 로그·작업 이력·백업·문의·포인트 및 잔여 활동 기록의 보존 근거/기간과 실제 파기 방법 확정.
- 7일 유예와 계정 연결 제거 후 기록 보존의 적정성 검토. 완전한 익명화로 단정하지 않음.
- 앱 약관 열람, 필요한 동의 UI, 동의 버전/시각 기록, 공개 URL 마련. 처리방침은 동의서와 구분.
- 운영 파기 배치 주기·실패 감시 및 실제 미디어 저장소 삭제 권한 검증.
- 일반 후기 삭제/사진 교체 시 이전 파일, 과거 고아 파일, 이미 탈퇴한 계정 사진,
  백업·캐시·EXIF 정리는 이번 구현과 별개. 본문에 완료로 적지 않음.
- 구버전 앱/외부 클라이언트가 사용하는 좌표 API와 기존 로그를 점검. 프런트 차단은 API 폐쇄가 아님.
