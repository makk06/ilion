# ILION 개인정보 처리방침

{{상호}}(이하 "회사")는 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 지킵니다.

회사가 어떤 개인정보를 어떤 목적으로 처리하고 얼마나 보관하는지 알려 드리기 위해 이 처리방침을 공개합니다.

## 제1조 개인정보의 처리 목적

회사는 다음 목적으로 개인정보를 처리합니다. 목적이 바뀌면 미리 알려 드리고 필요한 경우 동의를 받습니다.

| 목적 | 내용 |
|---|---|
| 회원 관리 | 계정 생성과 로그인, 본인 확인, 서비스 내 이용자 표시 |
| 서비스 제공 | 관광지 정보와 혼잡도 안내, 장소 검색과 추천 |
| 게시물 기능 | 후기 작성과 열람, 동행 모집 글 작성과 열람 |
| 개인 기능 | 여행 일정 관리, 즐겨찾기, 최근 본 장소 |
| 포인트 | 활동에 따른 포인트 적립과 조회 |
| 문의 응대 | 1:1 문의의 접수와 답변 |
| 위치 기반 안내 | (동의하신 경우) 현재 위치를 기준으로 주변 장소와 혼잡도 안내 |
| 서비스 개선 | (동의하신 경우) 추천 품질 개선과 이용 통계 |

## 제2조 처리하는 개인정보의 항목

### 1. 동의 없이 처리하는 항목 — 서비스 계약에 꼭 필요한 정보

이 항목들은 **계약을 맺고 이행하는 데 꼭 필요한 정보**입니다. 제공하지 않으시면 계정을 만들거나 해당 기능을 이용할 수 없습니다.

| 구분 | 항목 |
|---|---|
| 회원가입 | 이메일, 비밀번호, 닉네임, 생년월일 |
| 구글 로그인 이용 시 | 구글 계정 식별자, 이메일 (구글로부터 제공받음) |
| 계정 관리 | 가입 경로, 계정 상태, 가입일시, 인증 토큰 |
| 이용자가 만든 정보 | 후기(글·사진·평점), 동행 모집 글, 여행 일정, 즐겨찾기, 1:1 문의 |
| 자동 생성 | 포인트 적립 이력, 게시물 작성 시각 |
| 접속 시 자동 수집 | 접속 IP 주소, 접속 일시, 요청 주소, 브라우저·기기 정보(User-Agent) |

### 2. 동의를 받아 처리하는 항목

**동의하지 않으셔도 서비스를 이용하실 수 있습니다.**

| 구분 | 항목 | 동의 방식 |
|---|---|---|
| 서비스 개선·개인화 | 최근 본 장소, 선호 카테고리, 서비스 피드백 | 선택 동의 |
| 위치 기반 안내 | 현재 위치(위도·경도), 찾을 범위(반경) | **별도 동의** — [위치기반서비스 이용약관](location-service-terms.md) |
| 구글 로그인 | 인증 토큰의 국외 전송 | 선택 동의 (제6조) |

### 3. 회사가 수집하지 않는 것

- **만 14세 미만 아동의 개인정보**를 수집하지 않습니다.
- **주민등록번호 등 고유식별정보**를 수집하지 않습니다.
- **건강, 종교, 정치적 견해 등 민감한 정보**를 수집 항목으로 두지 않습니다.
  다만 후기·동행 글·문의 등 **직접 입력하시는 칸**에 그런 내용을 적으시면 그대로 저장됩니다. 민감한 정보는 입력하지 말아 주십시오.

### 탈퇴하시면 남는 것과 사라지는 것

탈퇴를 신청하시면 **7일 동안은 아무것도 지우지 않습니다.** 그 사이에 마음이 바뀌시면 로그인
화면에서 탈퇴를 취소하실 수 있고, 모든 정보가 그대로 돌아옵니다. 7일이 지나면 되돌릴 수 없습니다.

7일이 지나면 계정 정보와 여행 일정, 1:1 문의, 동행 모집 글, 포인트 이력은 모두 지워집니다.

후기와 즐겨찾기처럼 **서비스에 남는 기록**은 지우는 대신 **누가 남겼는지 알 수 없게** 바꿉니다.
바꾼 뒤에는 회사도 그것이 누구의 기록이었는지 알아낼 수 없습니다. 되돌리는 열쇠를 아예 만들지
않기 때문입니다. 이렇게 바꾼 기록은 개인을 알아볼 수 없으므로 기간 제한 없이 보관하며, 혼잡도
예측과 추천 품질을 높이는 데에만 씁니다.

**후기는 작성자 이름만 "탈퇴한 사용자"로 바뀌고 글과 사진은 그대로 남습니다.** 다른 이용자에게
도움이 되는 장소 정보이기 때문입니다. 글과 사진까지 지우고 싶으시면 **탈퇴하시기 전에 직접
삭제**해 주십시오. 직접 삭제하시면 사진 파일까지 함께 사라집니다.

동행 모집 글과 참여 이력은 남기지 않고 지웁니다. 연락이 닿지 않는 주최자의 모임이 남으면 다른
이용자가 피해를 보기 때문입니다.

탈퇴하신 뒤 **30일 동안은 같은 이메일로 다시 가입하실 수 없습니다.** 이 기간에는 이메일을
알아볼 수 없는 형태로만 보관합니다.
