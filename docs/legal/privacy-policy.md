# ⚠ 초안 — 선행 조치 완료 전 공개 불가

> **이 절은 팀 내부용입니다. 공개 시 이 절 전체를 삭제하고 [제1조](#제1조-개인정보의-처리-목적)부터 게시하십시오.**

## 이번 갱신의 범위와 공개 전 주의사항

- 기기 위치 측정은 프런트에서 차단하고, 후기에 현재 첨부된 사진은 7일 유예 후 계정 최종 파기 시 삭제하도록 반영했습니다.
- 일반 후기 삭제·사진 교체 시 이전 파일 삭제, 기존 고아 파일 정리, EXIF 제거는 **미구현**입니다. 이 문서는 이를 완료했다고 설명하지 않습니다.
- 연령 확인, 선택 동의, 보유기간 자동 파기, 앱 문서 열람·동의 이력은 미완료입니다. 미구현 기능을 이미 제공한다고 적었던 문구를 검토 대상으로 바꿨습니다.
- 운영자 정보와 보유기간을 임의로 채우지 않습니다. `[내부 검토]`와 `{{…}}`를 해소하고 실제 기능·운영 설정을 검증한 뒤 공개용 본문을 확정해야 합니다.

저장소는 공개 배포 설정을 포함하지만 이번 작업에서 운영 사이트의 게시 상태·로그·위탁 현황을 감사하지 않았습니다. 기존 보고서의 위반 단정을 현재 사실 확인으로 재사용하지 않습니다. 파기 및 처리방침 공개 사항은 [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법) 제21조·제30조에 따라 별도 검토합니다.

# ILION 개인정보 처리방침

{{상호}}(이하 "회사")는 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 지킵니다.

회사가 어떤 개인정보를 어떤 목적으로 처리하고 얼마나 보관하는지 알려 드리기 위해 이 처리방침을 공개합니다.

## 제1조 개인정보의 처리 목적

회사는 다음 목적으로 개인정보를 처리합니다. 목적이 바뀌면 미리 알려 드리고 필요한 경우 동의를 받습니다.

| 목적 | 내용 |
|---|---|
| 회원 관리 | 계정 생성과 로그인, 본인 확인, 서비스 내 이용자 표시 |
| 서비스 제공 | 관광지 정보와 혼잡도 안내, 장소 검색과 추천 |
| 게시물 기능 | 후기 작성과 열람, 동행 모집 글 작성과 열람 |
| 개인 기능 | 여행 일정 관리, 즐겨찾기, 최근 본 장소 |
| 포인트 | 활동에 따른 포인트 적립과 조회 |
| 문의 응대 | 1:1 문의의 접수와 답변 |
| 지역·장소 탐색 | 이용자가 직접 선택한 지역·관광지를 기준으로 장소와 혼잡도 안내. 기기 현재 위치는 측정하지 않음 |
| 개인화 | 선호 설정을 반영한 추천. 처리 근거·필요한 동의 절차는 공개 전 확정 |

## 제2조 처리하는 개인정보의 항목

### 1. 현재 처리하는 항목 — 처리 근거는 공개 전 확정

아래는 현재 코드에서 다루는 항목입니다. **[내부 검토]** 서비스 계약 이행 등 동의 외 처리 근거를 적용할 항목과 별도 동의가 필요한 항목을 구분하여 확정해야 합니다. 처리방침 열람을 모든 처리에 대한 일괄 동의로 취급하지 않습니다.

| 구분 | 항목 |
|---|---|
| 회원가입 | 이메일, 비밀번호, 닉네임. 생년월일은 수집하지 않음 |
| 구글 인증 API 이용 시 | 구글 계정 식별자, 이메일, 프로필 이미지 URL. 현재 Flutter 로그인 UI에는 미연결 |
| 계정 관리 | 가입 경로, 계정 상태, 가입일시, 인증 토큰 |
| 이용자가 만든 정보 | 후기(글·사진·평점), 동행 모집 글, 여행 일정, 즐겨찾기, 1:1 문의 |
| 자동 생성 | 포인트 적립 이력, 게시물 작성 시각 |
| 접속 시 자동 수집 | 접속 IP 주소, 접속 일시, 요청 주소, 브라우저·기기 정보(User-Agent) |

### 2. 개인화·이용 기록과 동의 구현 상태

**[내부 검토] 현재 별도 선택 동의 화면·동의 버전/시각 저장은 없습니다.** 아래 기능의 처리 근거·선택권과 고지 문안을 확정하고 구현한 뒤 공개 문구로 전환합니다.

| 구분 | 항목 | 동의 방식 |
|---|---|---|
| 개인 기능·개인화 | 최근 본 장소, 선호 설정, 서비스 피드백 | 별도 동의는 미구현. 최근 본 장소 목록 삭제 가능 |
| 기기 위치 | 현재 위치 측정 및 권한 요청 | 비활성화. 지역·장소 직접 선택 유지 |
| 구글 인증 API | 인증 토큰 검증 과정의 전송 | 앱 UI 미연결. 국외 이전 범위·근거·고지는 별도 확정 (제6조) |

### 3. 회사가 수집하지 않는 것

- 생년월일·기기 현재 위치는 현재 앱에서 수집하지 않습니다. **연령 확인 기능은 없으므로 아동의 가입이 기술적으로 차단된 상태는 아닙니다.**
- **주민등록번호 등 고유식별정보**를 수집하지 않습니다.
- **건강, 종교, 정치적 견해 등 민감한 정보**를 수집 항목으로 두지 않습니다.
  다만 후기·동행 글·문의 등 **직접 입력하시는 칸**에 그런 내용을 적으시면 그대로 저장됩니다. 민감한 정보는 입력하지 말아 주십시오.

## 제3조 개인정보의 처리 및 보유 기간

다음 표는 현재 구현과 미확정 정책을 구분한 **검토용 표**입니다. 미확정 기간은 공개 전에 확정하고, 그 기간에 맞는 파기 기능을 구현·검증해야 합니다.

### 탈퇴하시면 남는 것과 사라지는 것

탈퇴 신청 직후 로그인 세션을 종료하고 refresh 토큰을 삭제합니다. 계정과 게시물·사진은
**7일의 취소 유예기간 동안 유지**합니다. 이 기간에는 공개 후기·사진도 계속 보일 수 있습니다.
로그인 화면에서 본인 확인 후 취소할 수 있으며, 7일이 지난 뒤에는 취소할 수 없습니다.

유예기간이 지난 계정은 정기 파기 작업의 대상입니다. 최종 파기 시 계정 정보와 여행 일정,
1:1 문의, 동행 모집 글, 포인트 이력을 삭제합니다. **후기에 현재 첨부된 사진 파일도 삭제하고
사진 URL 참조를 비웁니다.** 파일 삭제에 실패한 계정은 다음 파기 작업에서 재시도합니다.

후기 글·평점 및 일부 활동 기록은 계정 연결을 제거하고 남깁니다. 작성자는 "탈퇴한 사용자"로
표시됩니다. **글 자체에 개인정보가 남을 수 있으므로 완전한 익명정보라고 단정하지 않습니다.**
후기 글까지 없애려면 탈퇴 전에 수정하거나 삭제해 주십시오.

**[내부 검토]** 운영 파기 배치 주기·실패 감시·백업 보존기간은 확정되지 않았습니다. 과거 사진
교체·후기 삭제로 DB 참조가 끊긴 파일과 이미 파기된 계정의 잔존 사진은 이 파기 로직의 자동
처리 대상이 아닙니다. 기존 데이터 점검·별도 정리 계획이 필요하며 이번 작업에서는 실행하지 않았습니다.

동행 모집 글과 참여 이력은 남기지 않고 지웁니다. 연락이 닿지 않는 주최자의 모임이 남으면 다른
이용자가 피해를 보기 때문입니다.

계정 최종 파기 후 **30일 동안은 같은 이메일로 다시 가입하실 수 없습니다.** 이 기간에는 이메일
원문 대신 재가입 차단용 HMAC 지문을 보관합니다. 지문 만료는 날짜 단위로 처리합니다.

### 지역·장소 선택 및 사진의 위치 관련 정보

현재 앱은 기기의 현재 위치를 측정하거나 위치 권한을 요청하지 않습니다. 직접 선택한 지역·관광지의
주소와 좌표는 검색·지도·주변 장소 조회에 사용합니다. 관광지 좌표를 이용자의 현재 위치로 간주하지 않습니다.

사진 업로드 시 EXIF 메타데이터를 별도로 제거하지 않습니다. **사진 파일에 촬영 위치·시각 등이 포함되어
있을 수 있습니다.** 이를 추출하여 현재 위치 검색이나 방문 인증에 사용하는 코드는 없습니다.
백엔드의 좌표 입력 API는 유지되므로, 구버전 앱·직접 API 호출 및 기존 로그에 좌표가 남는지는 별도
운영 점검 대상입니다. 위치 약관은 [재활성화 검토용](location-service-terms.md)으로 보류합니다.

서비스의 정책을 따릅니다. **[내부 검토]** 실제 타일 제공자·프록시·대체 경로와 전송 항목을 점검하기
전에는 모든 지도 경로에서 접속 정보가 전달되지 않거나 국외 이전이 없다고 단정하지 않습니다.

## 제7조 개인정보의 파기 절차 및 방법

1. 회사는 보유 기간이 지나거나 처리 목적이 달성되면 **지체 없이** 개인정보를 파기합니다.
2. 파기 방법은 다음과 같습니다.
   - 전자적 파일: 복구할 수 없는 방법으로 삭제
   - 종이 문서: 분쇄하거나 소각
3. 탈퇴 신청 후 7일 유예가 지나 **계정 최종 파기 시 현재 후기에 첨부된 사진 파일을 삭제**합니다. 파일 삭제 실패 시 계정 파기를 완료 처리하지 않고 다음 작업에서 재시도합니다.
4. 법령에 따라 보관해야 하는 정보는 다른 개인정보와 분리하여 보관하고, 보관 목적 외의 용도로 이용하지 않습니다.

**[내부 검토]** 일반 후기 삭제·사진 교체의 이전 파일 삭제와 백업 파기 정책은 미완료입니다.
현재 저장소의 파일 삭제 호출만으로 백업·캐시·저장매체 전체의 복구 불가능성을 보장하지 않습니다.
파일 삭제는 DB 트랜잭션으로 복구되지 않으므로 유예기간 경과 후 일부 파일이 먼저 삭제되고
나머지 계정 처리가 재시도될 수 있습니다.

- **삭제** 요구
- 처리의 **정지** 요구
- 동의를 하신 항목에 대한 **동의 철회**

|---|---|

1. 회사는 요구를 받으면 **지체 없이** 처리합니다.
2. 열람이나 정정을 요구하신 경우, 처리가 끝날 때까지 해당 정보를 이용하거나 제공하지 않습니다.

### 4. 회원 탈퇴

## 제11조 자동화된 결정에 관한 사항

현재 앱의 추천 화면은 앱 내부 `RecommendationEngine`을 사용합니다. 별도로 구현된 백엔드 추천 API와
아직 연결되지 않았습니다. 다음 설명은 현재 프런트 구현 기준이며 연결 변경 시 다시 검토합니다.

### 1. 무엇을 근거로 하는가

| 근거 | 설명 |
|---|---|
| 거리 | 직접 선택한 기준 관광지와의 거리 등 사용 가능한 장소 정보. 기기의 현재 위치를 측정하지 않음 |
| 혼잡도 | 현재 또는 방문 예정 시각의 붐비는 정도 |
| 날씨·장소 유형 | 전달받은 장소 정보와 이용자가 설정한 날씨·실내외 선호. 실시간 예보 연동 여부와 구분 |
| 카테고리 | 이용자가 선택하신 조건에 맞는 정도 |
| **회원의 선호 카테고리** | 로그인하신 경우, **설정에 저장하신 선호 카테고리**를 반영합니다 |

### 2. 무엇을 근거로 하지 않는가

> **회사는 추천 순서를 정할 때 다음을 이용하지 않습니다.**
> - 즐겨찾기(찜)한 장소
> - 최근 본 장소
> - 작성하신 후기나 피드백

### 3. 결과의 보관

현재 앱 내부에서 계산한 추천 순위의 별도 저장 경로는 없습니다. 다만 이용자가 장소를 열거나
즐겨찾기·후기·피드백 기능을 사용하면 해당 기능의 기록은 저장됩니다. 운영 접속 로그까지 기록이
전혀 없다는 뜻은 아닙니다.

### 4. 이용자의 권리

추천에 적용할 선호 설정을 변경하실 수 있습니다. **[내부 검토]** 개인화 중단·동의 철회 기능과
화면 고지는 아직 확정되지 않았습니다. 추천 기준에 대한 설명은 {{고객센터 경로}}로 요청하실 수 있습니다.
