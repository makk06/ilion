**로컬 코드·문서 작업과 커밋만 수행. 푸시·병합·배포·운영 데이터 파기는 하지 않음.**

## 이번 구현 범위

- 기기 위치 기능을 제거하지 않고 비활성화: 홈/지도 위치 버튼 숨김, 플랫폼 호출 전 서비스 차단,
  Android/iOS 위치 권한 선언 비활성화. 지역 직접 선택·관광지 기준 주변 장소 조회 유지.
- 기존 7일 탈퇴 철회 기간 유지. 최종 파기 시 현재 첨부 사진 파일을 삭제하고 `photo_url`을 비움.
  후기 본문·평점 및 기존 활동 기록의 보존 정책은 유지.
- 파일 삭제 실패 계정은 DB 참조를 보존하여 다음 배치에서 재시도. 다른 계정은 계속 처리.
  파일이 먼저 지워지고 DB 처리가 실패한 경우에도 재실행 가능.
- 탈퇴 화면 안내와 법적 문서 갱신. 위치 약관은 미적용으로 보류. 미확정 운영 정보·정책은 빈칸 유지.
- 전체 법률 검토 완료를 뜻하지 않음. 기존 조사 자료는 과거 이력으로 표시하고
  [현재 문서 색인](legal/README.md)으로 연결.

## 보류 범위와 남은 위험

- 기존 4번 중 **탈퇴 시 현재 첨부 사진 삭제만** 이번에 처리함. 일반 후기 삭제·사진 교체의 이전
  파일 정리, EXIF 제거, 과거 고아 파일과 이미 최종 파기된 계정의 사진 정리는 별도 작업.
- 기존 파일을 전수 삭제하거나 운영 파기 명령을 실행하지 않음. 백업/캐시의 사본까지 이번 코드로
  정리되는 것은 아님. 실제 파일 삭제는 되돌릴 수 없어 운영 검증은 별도 승인된 테스트 계정으로 해야 함.
- 기존 5번 비밀번호 분실 복구·추가 보안 정비는 보류 유지. 이미 있는 비밀번호 변경은 변경하지 않음.
- 문서는 검토용 초안. 가입 연령 확인, 동의 화면/기록, 기간 경과 자동 파기, 잔여 기록의 보존 근거는
  아직 미완료이며 초안을 그대로 공개용으로 게시하지 않음.

## 검증

- Django 전체 테스트: 311개 통과 (새 사진 파기 회귀 테스트 포함).
- Django `makemigrations --check --dry-run`: 변경 없음. 운영 DB 마이그레이션 추가 불필요.
- Django `check --deploy --fail-level WARNING`: 테스트용 운영 설정에서 통과. 실제 운영 설정 검증과는 별개.
- Flutter 3.47.5 / Dart 3.13.4: `analyze --no-pub` 통과, 전체 테스트 98개 통과.
  390×844와 1440×1000에서 홈/지도 위치 버튼 미노출, 수동 지역 선택 및 좌표 미전송,
  위치 서비스 직접 호출 차단, 탈퇴 안내 문구를 검증.
- Flutter 웹 빌드 통과. 로컬 검증용 `API_BASE_URL=http://127.0.0.1:18765/api`를 사용했으며
  **배포용 빌드가 아님**. 의존성은 `pub get --enforce-lockfile`로 준비했고 lockfile 변경 없음.
- Android 소스 manifest의 활성 위치 권한 0개, iOS plist 문법 검사 통과.
  최종 Android merged manifest·서명 패키지 및 실기기 테스트는 아직 수행하지 않음.
- 격리된 임시 SQLite에 신규 마이그레이션·개발 장소 시드 후 Chrome에서 홈의 위치 버튼 비노출과
  지역 직접 선택을 확인 (1440×1000 / 390×844). 지도 제공자 키 없이 실행하여 배경 타일은
  불러오지 못했으며, 실운영 지도 연동 통과를 뜻하지 않음.
- 운영 서버·DB·사진은 조회/변경하지 않음. 임시 SDK·검증 DB는 `/private/tmp`에 보존.
